# Submission Belajar Dasar Pemrograman Web

Proyek ini merupakan submission Dicoding untuk kelas **Belajar Dasar Pemrograman Web**. Aplikasi berupa website portofolio pribadi Muhammad Reza Pahlevi Harahap dengan fokus pada Data Analytics, Machine Learning, dan Artificial Intelligence.

## Fitur utama

- Struktur HTML semantik.
- Navigasi ke Tentang, Keahlian, dan Proyek.
- Layout responsif menggunakan CSS Flexbox dan media query.
- Elemen `article` dan `aside` untuk konten utama dan profil.
- Menu responsif untuk perangkat mobile.
- Pergantian tema terang/gelap.
- Tahun footer dinamis menggunakan JavaScript.

## Teknologi

HTML5, CSS3, dan JavaScript murni tanpa framework.

## Menjalankan proyek

Buka `index.html` melalui browser.
