# Belajar Pengembangan Web Intermediate — Cerita Nusantara

ZIP 5.1 adalah versi Proyek Pertama Cerita Nusantara: SPA dengan hash routing, MVP, autentikasi, Story API, peta Leaflet, pengambilan foto melalui kamera, dan pemilihan lokasi.

ZIP 5.2 adalah versi lanjutan/Proyek Akhir yang menambahkan PWA, Service Worker, IndexedDB, push notification, offline mode, dan workflow deployment. Versi 5.2 sudah tersimpan lengkap pada repository **`RezaHarahap/cerita-nusantara`**, sehingga tidak diduplikasi di repository ini.

Repository final: https://github.com/RezaHarahap/cerita-nusantara
