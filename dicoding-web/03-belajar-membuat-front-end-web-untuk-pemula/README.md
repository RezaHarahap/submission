# Personal Finance & Expense Tracker

Proyek ini merupakan submission Dicoding untuk kelas **Belajar Membuat Front-End Web untuk Pemula**. Aplikasi digunakan untuk mencatat pemasukan dan pengeluaran langsung di browser.

## Fitur utama

- Tambah, edit, ubah tipe, dan hapus transaksi.
- Pencarian transaksi berdasarkan judul.
- Perhitungan otomatis pemasukan, pengeluaran, dan saldo.
- Penyimpanan menggunakan `localStorage`.
- Manipulasi DOM dan custom event `transaction:updated`.
- Validasi judul, nominal, dan tanggal.

## Teknologi

HTML5, CSS3, JavaScript DOM, dan Web Storage.
