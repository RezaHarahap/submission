# Submission Belajar Dasar Pemrograman JavaScript

Folder ini berisi rangkaian asesmen dan latihan kelas **Belajar Dasar Pemrograman JavaScript** Dicoding.

## Materi yang dikerjakan

- Penulisan komentar JavaScript.
- Konsistensi gaya penulisan kode.
- Pengujian fungsi menggunakan `node:test` dan `node:assert`.
- Object-Oriented Programming menggunakan ES6 Class.
- Rekursi untuk faktorial dan Fibonacci.
- Pengujian dengan cakupan kondisi lebih lengkap.
- Studi kasus pengelolaan pesanan: tambah pesanan, ubah status, hitung pendapatan, dan hapus pesanan.

## Berkas proyek

Arsip source asli tersedia pada `submission.zip` di folder ini.
