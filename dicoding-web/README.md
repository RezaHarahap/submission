# Kumpulan Submission Dicoding — Web Development

Folder ini berisi dokumentasi proyek dan asesmen web development yang dikerjakan oleh **Muhammad Reza Pahlevi Harahap** pada kelas-kelas Dicoding.

## Daftar proyek

1. **Belajar Dasar Pemrograman Web** — website portofolio pribadi dengan HTML, CSS, dan JavaScript.
2. **Belajar Dasar Pemrograman JavaScript** — asesmen dasar JavaScript, testing, OOP, rekursi, dan studi kasus pesanan.
3. **Belajar Membuat Front-End Web untuk Pemula** — Personal Finance & Expense Tracker berbasis DOM dan Web Storage.
4. **Belajar Fundamental Front-End Web Development** — Proyek Pertama Ruang Catatan dan Proyek Akhir integrasi Notes API.
5. **Belajar Pengembangan Web Intermediate** — Proyek Pertama Cerita Nusantara; versi lanjutan/final sudah tersedia di repository `cerita-nusantara`.

Setiap folder memiliki `README.md` berbahasa Indonesia yang menjelaskan tujuan, fitur, teknologi, dan cara menjalankan proyek.
