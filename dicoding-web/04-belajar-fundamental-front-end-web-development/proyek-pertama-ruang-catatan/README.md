# Ruang Catatan — Proyek Pertama

Proyek ini merupakan Proyek Pertama kelas Dicoding **Belajar Fundamental Front-End Web Development**.

## Fitur utama

- Menampilkan 15 data catatan awal.
- Menambah catatan dan validasi formulir realtime.
- Tiga custom element: `app-header`, `note-form`, dan `note-item`.
- Custom attribute.
- CSS Grid responsif.
- Pencarian, arsip/pulihkan, dan hapus catatan.
- Penyimpanan perubahan menggunakan `localStorage`.
- Shortcut `Ctrl + Enter` untuk menyimpan.
