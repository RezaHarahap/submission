# Ruang Catatan — Integrasi Notes API

Proyek ini merupakan Proyek Akhir kelas Dicoding **Belajar Fundamental Front-End Web Development**.

## Fitur utama

- Mengambil daftar catatan aktif dan arsip dari Notes API V2 Dicoding.
- Menambah, menghapus, mengarsipkan, dan memulihkan catatan melalui REST API.
- Fetch API dan asynchronous JavaScript.
- Web Components.
- Loading indicator dan SweetAlert2.
- Pencarian/filter catatan.
- Webpack untuk development dan production build.
- npm dan Prettier.

## Menjalankan proyek

```bash
npm install
npm run start-dev
```
