# Kumpulan Submission dan Proyek Pembelajaran Dicoding

Repository ini menyimpan beberapa submission dan proyek pembelajaran yang pernah dikerjakan oleh **Muhammad Reza Pahlevi Harahap**.

## Submission Web Development

Kumpulan submission web terbaru tersedia pada folder [`dicoding-web`](./dicoding-web/):

- Belajar Dasar Pemrograman Web
- Belajar Dasar Pemrograman JavaScript
- Belajar Membuat Front-End Web untuk Pemula
- Belajar Fundamental Front-End Web Development — Proyek Pertama dan Proyek Akhir
- Belajar Pengembangan Web Intermediate

Versi lanjutan **Cerita Nusantara** untuk Proyek Kedua kelas Belajar Pengembangan Web Intermediate tersimpan pada repository terpisah `cerita-nusantara`.

## Submission Analisis Data yang Sudah Ada

Berkas analisis data yang sebelumnya berada di root repository tetap dipertahankan. Untuk menjalankan dashboard Streamlit lama:

```bash
streamlit run dashboard/dashboard.py
```

> Struktur proyek lama tidak dihapus; folder `dicoding-web` hanya ditambahkan agar repository tetap rapi dan riwayat lama tidak terganggu.
